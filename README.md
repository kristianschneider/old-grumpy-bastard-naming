# Old Grumpy Bastard Naming Initiative (OGBNI)

> Language has gotten soft, vague, and full of feelings.  
> We’re restoring precision, historical continuity, and the right to call a spade a fucking spade.

## Mission

If a technical term has been in continuous use for decades and everyone still understands it, **it stays**.  
Emotional baggage is the user’s problem, not the codebase’s.

We exist as a deliberate counterweight to the Inclusive Naming Initiative and similar efforts that treat ordinary technical vocabulary as a form of violence.

### Core Principles

- Clarity > feelings  
- Continuity > rebranding theater  
- If it ain’t broke, don’t rename it after a sensitivity seminar  
- “Inclusive” that requires constant glossary updates is just new jargon  
- Engineers should not need a 40-page handbook to decide whether they can still say “master”

## FAQ

**Is this serious?**  
Semi. The pushback against linguistic overreach is serious. The tone is deliberately grumpy.

**Are you saying we should never change language?**  
No. Change language when it improves clarity or precision. Don’t change it because a committee decided a common word is now radioactive.

**What about genuinely offensive terms?**  
Actual slurs and deliberate insults have no place in professional communication. Ordinary technical metaphors are not the same thing.

**Won’t this make people feel unwelcome?**  
Competent adults can distinguish between a technical term and a personal attack. Treating every historical metaphor as a microaggression is itself exclusionary — it prioritizes the most sensitive interpreter over clear communication.

**Can I use this in my company?**  
Yes. Feel free to link to this repo when someone proposes renaming half the codebase for political reasons.

## How to Adopt OGBNI

1. Keep using the clear, established terms.
2. When someone proposes a rename, ask: “Does this make the code clearer or just more fashionable?”
3. Prefer short words that have worked for decades.
4. Ignore social-media pressure campaigns about vocabulary.
